# Runnable examples

[Home](../README.md) · [Detailed code index](../reference/code-index.md) · [Runner commands](../scripts/README.md)

21 standalone programs: 3 tiny starter programs and 18 explained phase examples. Each folder is an independent compilation unit; repeated helper names are intentional. Source filenames and class names are preserved. Twenty sources are unchanged; the inheritance example has one corrected reference type so its `instanceof Cat` check compiles.

Run these commands from the repository root:

```bash
python3 scripts/java.py list
python3 scripts/java.py run Phase0_HelloWorld
python3 scripts/java.py run Phase0_CommandLineArgs hello "Java learner"
python3 scripts/java.py check
python3 scripts/java.py smoke
```
