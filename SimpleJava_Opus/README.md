## 🚀 How to Use This Tutorial

1. Start from **Lesson 1** and go in order.
2. Read the explanation carefully.
3. Type out every code example yourself (don't copy-paste!).
4. Do the exercises and quizzes at the end of each lesson.
5. Don't move on until you understand the current lesson.
6. Build the projects in Lesson 71 to practice everything.

## 📋 Prerequisites

- No prior programming experience required.
- A computer with JDK 17+ installed.
- A text editor or IDE (IntelliJ IDEA recommended).
